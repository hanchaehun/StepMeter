# 0006. 팀원 간 질문·전달은 GitHub 이슈로 한다

- **날짜:** 2026-10-29 (AGENTS.md 협업 지침)
- **근거 기록:** [AGENTS.md](../../AGENTS.md) "협업 시 전달할 것이 있다면"

## 배경

역할 배정과 협업 규칙은 팀 노션에서 관리한다([README.md](../../README.md)). 역할 사이의 질문·요청을 어디에 남길지는 따로 정해야 했다.

## 결정

다른 역할에게 묻거나 전달할 것은 GitHub 이슈로 남긴다. 이슈에는 제목, 받는 사람(역할), 내용을 적는다.
AI 코딩 에이전트는 이슈를 직접 등록하지 않고 사용자에게 초안을 제안한다.

## 대안

- 메신저나 노션 댓글로 전달한다.
