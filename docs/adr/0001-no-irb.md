# 0001. 사람 실험은 IRB 심의를 받지 않는다

- **날짜:** 2026-10-31 (PM 결정)
- **근거 기록:** [human-study/consent-form.md](../../human-study/consent-form.md) "결정된 사항"

## 배경

개발계획서 9.1은 11월 2일까지 IRB 확인을 받은 경우에만 외부 참가자 실험을 하도록 했다.

## 결정

IRB 심의를 받지 않고 문의도 하지 않는다. 학회 프로젝트이기 때문이다.
사람 실험은 `human-study/consent-form.md`의 동의서와 운영 메모를 따른다.
사람 데이터로 보정하지 못하면 소요 시간은 문헌값만 쓰고 리포트에 '보정'이라고 표시하지 않는다(개발계획서 5.10).

## 대안

- 계획서 원안: 11월 2일까지 IRB 확인을 받고, 확인이 안 되면 팀원 데이터로 파이프라인만 검증한다.
