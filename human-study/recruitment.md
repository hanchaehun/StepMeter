# 사람 실험 모집 공고

사람 실험 참가자 모집 공고 문안이다. 구분선 아래를 그대로 복사해 쓰고, `[ ]` 자리는 게시할 때만 채운다.

- **담당:** 대시보드 UI (모집·세션 운영)
- **맞춰야 하는 문서:** [동의서](consent-form.md) 2·3·4·7절, [세션 진행 절차](session-procedure.md)
- **레포에 채우지 않는 것:** 신청 받는 연락처, 진행자 이름. 레포가 public이다. 신청자 이름·연락처는 일정 조율에만 쓰고, 참가자 코드와 잇는 표를 만들지 않는다(동의서 운영 메모).
- **사례:** 약속하지 않는다(동의서 결정 사항). 공고에 사례 문구를 넣지 않는다.
- **템플릿 이름을 적지 않는다:** 미리 검색해 보면 "처음 보는 사람" 조건이 깨진다. 이름은 세션 시작 전 구두 확인(`session-procedure.md` C-1)에서만 말한다.

## [StepMeter] 웹 화면 사용 실험 참가자를 모집합니다 (20분)

웹 화면에서 간단한 일을 할 때 걸리는 시간을 재는 실험입니다. 자동 측정 도구(StepMeter)가 예측한 시간이 실제 사람과 얼마나 다른지 확인하려고 합니다.

**이런 분을 찾습니다**
- 평소에 컴퓨터와 마우스를 쓰시는 분
- 웹 개발에 쓰는 **관리자 대시보드 템플릿을 써 보거나 만들어 본 적 없는 분**
  - 처음 보는 사람의 기록이 필요해서입니다. 잘 모르시겠으면 신청하셔도 됩니다. 시작 전에 한 번 더 여쭤봅니다.

**무엇을 하나요**
- 준비된 웹 페이지 6개에서 "회원가입 양식을 채운다", "목록에서 원하는 항목을 찾아 편집 화면을 연다" 같은 간단한 일을 순서대로 합니다.
- 진행자가 준비한 컴퓨터와 마우스를 씁니다. 개인 기기는 필요 없습니다.
- 잘하거나 빨리 할 필요가 없습니다. 능력을 평가하지 않습니다.

**시간과 장소**
- 20분 이내 (1인씩)
- 일정: [날짜·시간대]
- 장소: [장소]

**기록하는 것과 하지 않는 것**
- 마우스 움직임·클릭·스크롤의 위치와 시각, 키를 누른 시각과 횟수를 기록합니다.
- **이름·학번·연락처는 기록하지 않습니다.** 참가자 코드(예: P01)로만 다룹니다.
- **입력한 글자는 저장하지 않습니다.** 화면 녹화·사진·음성도 남기지 않습니다.
- 자료는 2026년 12월 31일까지 보관한 뒤 지웁니다.
- 시작 전에 동의서로 자세히 설명드리고, 하는 중에 언제든 그만두실 수 있습니다.
