## 추가한 구현

1. Compose 기본 API 명령 연결 및 실제 API/DB/Redis 검사: 임시 코드 발급, 인증/소유권 분리,
   프로젝트·과업·측정 생성, 큐 등록, 대기 중 취소, 스크린샷 HTTP 제공. 코드는 검사 후 비활성화하고 원문을 로그에 남기지 않음.
2. R06은 과업의 첫 대상이 하나뿐인 진입 페이지로 수정하고 같은 axe 베이스라인 경로를 사용.
3. build_variant.py는 원본 체크아웃을 보존하고 고정 커밋→기준선→변이 소스 패치를 격리 재현하며 SHA256 기록.
4. React 앱도 소스 패치로 변이를 주입. 입력/클릭 후 재렌더링해도 작은 타겟 결함이 유지됨을 확인.
5. MUI 정상판의 이름·대화상자 의미·장식 배경과 배경막을 정리해 동적 상태를 검증.
6. 커머스는 CRA4/node-sass를 Vite/Dart Sass로 교체하고 package-lock·로컬 JSON/SVG를 포함. 외부 요청 0건을 확인.
7. verify_development.py와 월요일 09:00 KST/수동 개발 검사 워크플로 추가. 홀드아웃 설정을 읽지 않음.
8. 진짜 M2 E2E 실행기는 실제 agent가 없으면 exit 2. 제공되면 임시 코드와 명시적 API/fixture 주소로 tests/e2e를 실행.
9. 소스 보존·패치 순서·덮어쓰기 거부·홀드아웃 거부·미완성 제출 차단 테스트 추가.
