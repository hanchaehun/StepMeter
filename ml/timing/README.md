# ml/timing/

- **담당 역할:** 측정 지표·규칙
- **하는 일:** 소요 시간 모델 (문헌 KLM + 보정 계수). 사람 실험은 IRB 심의 없이 동의서를 받아 진행한다([ADR 0001](../../docs/adr/0001-no-irb.md)). 사람 데이터로 보정하지 못하면 문헌값만 쓰며 리포트에 '보정'이라고 표시하지 않는다. 사람 실험은 그대로 진행하고 KLM 보정 완성만 선택 항목이다. 시간이 부족하면 사람 측정값과 예측값 비교만 발표에 넣는다([ADR 0008](../../docs/adr/0008-schedule-to-1204.md)).
- **참고:** 개발계획서 5.10, 9.1

## ADR 0011에 따른 할 일

결정 내용은 [ADR 0011](../../docs/adr/0011-w3-plan-gaps.md)에 있다.

- 필수(W4): 사람 실험 6페이지에서 참가자 과업 시간의 중앙값과 같은 페이지 run의 `est_task_time`을 비교해 평균 오차율과 스피어만 순위 상관을 낸다. 예측에 R이 없으므로 사람 쪽도 R 구간을 뺀다 (ADR 0011 3번)
- 과업 시간을 어디서 어디까지로 볼지는 결과를 보기 전에 이 문서에 적는다 (ADR 0011 3번)
- 보정 계수와 Fitts 식 대체는 선택이다 (ADR 0011 3번)
- 사람 측정값은 서버가 아니라 수집한 JSON 파일에서 읽는다(`POST /human-sessions`는 만들지 않는다). 파일은 팀 Notion의 팀원 전용 페이지에서 받아 로컬 `data/human/`(git 제외)에 두고, 저장소에 올리지 않는다 (ADR 0011 4번)
- 화면 안정 시점은 click·key 뒤에 처음 나온 `stable`만 쓴다. 다음 행동 전까지 더 나온 `stable`(마우스를 올려 생긴 것 포함)은 쓰지 않는다. 생각 시간(M) 표본과 R 구간 계산에 같은 기준을 쓴다 (ADR 0011 3번)
