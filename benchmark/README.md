# benchmark/

- **담당 역할:** 회귀 비교·인프라 (결함 주입 총괄·평가). 앱별 결함 주입과 정답은 리포트 UI, 대시보드 UI, LLM·프롬프트, 플랫폼 백엔드가 나눠 맡고 PM이 교차 검토한다.
- **하는 일:** `apps/` 포크한 오픈소스 앱(개발 4 + 홀드아웃 2), `mutations/{app}/{variant}.yaml` 결함 주입 설정, `labels/{page}.json` 정답, `eval.py` 평가 스크립트. 정답에는 렌더링 결과로 발현을 확인한 결함만 넣는다. CI에서 매주 월요일에 개발 앱만 평가하고, 홀드아웃 앱은 W7 최종 평가 때 한 번만 돌린다.
- **주의:** 측정 지표·규칙과 수집·매칭 담당은 홀드아웃 앱 2개의 설정과 정답을 최종 평가 전까지 보지 않는다.
- **참고:** 개발계획서 8장
